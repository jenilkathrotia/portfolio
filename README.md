## Overview

A clean, responsive portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no bloat. Features a dark mode toggle, smooth scroll navigation, project search, and a contact form.

## Features

- **Dark / Light Mode** — toggle between themes with persistent preference
- **Responsive Layout** — adapts across desktop, tablet, and mobile
- **Project Search** — filter projects by keyword in real time
- **Smooth Scroll Navigation** — section-based single-page navigation
- **Contact Form** — reach out directly from the site
- **Resume Download** — one-click access to a PDF resume

## Run Locally

Clone the repo and open `index.html` in a browser — no build step needed.

```bash
git clone https://github.com/jenilkathrotia/portfolio.git
cd portfolio
open index.html
```

Or use a local dev server:

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

Then visit `http://localhost:8000`.
